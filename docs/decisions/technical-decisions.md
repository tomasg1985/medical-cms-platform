# Decisión 001

## Cambio de Flask a FastAPI

Estado:

Aceptado

Fecha:

Agosto 2026


## Motivo

El proyecto requiere una API moderna y escalable.

FastAPI ofrece:

- Mejor integración con Python moderno.
- Validación automática.
- Documentación OpenAPI.
- Excelente rendimiento.

# Decisión 002

## Cambio de Sequelize a SQLAlchemy

Estado:

Aceptado


## Motivo

SQLAlchemy es el ORM estándar dentro del ecosistema Python y tiene integración directa con FastAPI.
